# Features

- Department Selection: Browse through specialized medical departments like Medicine, Cardiology, Dental, Gynecology, and Surgery.

- Dedicated Doctor Profiles: View multiple expert doctors under each department, complete with their name, qualification, experience, and direct contact email.

- Interactive Date & Time Slot Selection: Pick a specific appointment date and choose from available real-time schedule slots.

- Instant Booking Confirmation: Recieve an immediate popup modal summarizing the confirmed appointment details, including doctor, department, date, and time.

- Modern Responsive UI: Built with a clean, mobile-friendly interface designed for quick navigation during both regular visits and emergency situations.
